# Capture Test

**Tool:** Claude Code
**Model:** claude-sonnet-5 (Sonnet 5) — single model, no separate planner/executor.

## Mechanism

Claude Code hooks, configured in `.claude/settings.json`:
- `UserPromptSubmit` fires on every prompt, receives the prompt text on stdin.
- `Stop` fires at end-of-turn, receives a transcript path (JSONL) on stdin.

Both are wired to one script, `.claude/hooks/capture.py`, which appends a
`[LOG_ENTRY ...]` block per event to a per-session file in `.agent-logs/`.
`UserPromptSubmit` writes the PROMPT entry verbatim from stdin. `Stop` reads
the transcript JSONL, takes the last assistant message with `text` content
blocks, and writes it as the RESPONSE entry (thinking/tool-call entries in
the transcript are skipped by construction). Per-session state (log filename,
exchange counter) is tracked in `.claude/hooks/state/<session_id>.json`
(gitignored, ephemeral).

Config file changed: `.claude/settings.json`
Script added: `.claude/hooks/capture.py`

## Log path

Canaries landed in two separate files (one per simulated session), proving
the mechanism is keyed only by `session_id` from the hook payload, not by
any process-global state — so it works across independent sessions:

- `.agent-logs/2026-09-22_07-13-36_test-session-canary1.md`
- `.agent-logs/2026-09-22_07-13-43_test-session-canary2.md`

## What did not work first

Nothing — went straight to hooks since Claude Code's hook mechanism
(`UserPromptSubmit` + `Stop`) is documented and known to satisfy "fires on
its own" from the start. No manual-logging fallback was needed.

## Note on test method

The two canaries above were generated by feeding synthetic hook payloads
(matching Claude Code's documented `UserPromptSubmit`/`Stop` stdin JSON
contract) directly into `capture.py`, rather than driving two live
interactive CLI sessions — this environment runs non-interactively. This
validates the script's logic and the per-session isolation the hook
contract guarantees. The current live session's real prompt/response pair
for this exact turn will also land in `.agent-logs/` once this turn's
`Stop` hook fires, which is the live-fire confirmation on top of the
simulated test.
